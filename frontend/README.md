# NewsWireHub UI

See the [root README](../README.md) for full setup, configuration, and deployment instructions.

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) and upgraded to Angular 20.

## Development server

Run `npm start` (`ng serve`) for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## Build

Run `npm run build` (`ng build`) to build the project. The build artifacts will be stored in the `dist/` directory.

## Running unit tests

Run `npm test` (`ng test`) to execute the unit tests via [Karma](https://karma-runner.github.io).
